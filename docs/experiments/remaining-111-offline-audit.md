# 인용 검사와 Skill 참조 누락 분석

2026-11-15에 저장된 답변 60개와 읽기 기록을 분석했습니다. 추가 모델 호출은 0회입니다. 원래 답변·정답지·채점 결과는 수정하지 않았습니다. 분석은 AI가 수행했으며 사람 검토 완료를 뜻하지 않습니다.

## 왜 조건마다 2건만 통과했나

검사기는 인용 항목 하나라도 실패하면 답변 전체를 탈락시킵니다. A/B/C 각각 20개 답변 중 2개만 통과했지만, 개별 인용으로 보면 총 176개 중 69개가 통과하고 107개가 실패했습니다. 답변 단위의 6/60을 모든 근거가 틀린 비율로 해석할 수 없습니다.

저장된 60개 답변에 같은 검사기와 편람·표 색인을 적용하니 기존 판정이 모두 재현됐습니다. 실패 107개는 중복을 묶으면 82개 인용문입니다. 해당 16개 PDF 페이지를 이미지로 확인하고 추출 텍스트·표 관계와 대조했습니다.

| 실패 인용의 형태 | 개수 | 해석 |
| --- | ---: | --- |
| 표 셀·제목을 이어 쓰거나 재배열한 인용 | 79 | 검사 범위와 출력 표현이 맞지 않는 경우가 많음. 아래 쉼표 처리 실패 16개 포함 |
| 따옴표 모양·유무만 다른 인용 | 15 | 내용 차이와 엄격한 원문 복사 실패를 구분해야 함 |
| 단어 변경·오타·단위 추가 | 10 | 원문 그대로 인용하라는 지시를 지키지 않음. 모두 의미 오류라는 뜻은 아님 |
| 인용 메타데이터 형식 오류 | 2 | 페이지 뒤의 불필요한 세미콜론 때문에 파싱 실패 |
| 표의 지정 유형을 잘못 연결 | 1 | 실제 근거 해석 오류 확인 |
| 합계 | 107 | 인용 항목 수이며 답변 수가 아님 |

이 분류는 실패한 인용의 표현과 확인된 오류 유형을 나눈 것입니다. 각 답변 전체의 정책 적용·계산·근거 충분성을 새로 채점한 결과가 아닙니다. 표 재구성 79개를 모두 올바른 인용으로 재분류하지 않았습니다.

## 검사기에서 놓친 부분

### 1. 지원하는 표도 쉼표를 넣으면 매칭하지 못함

편람 53쪽에서 역사와사상 영역의 한국현대사는 3학점입니다. 같은 표 색인으로 다음 두 표현을 검사했습니다.

| 진단 입력 | 현재 표 검사 결과 |
| --- | --- |
| `역사와사상, 한국현대사, 3` | `not_applicable` |
| `역사와사상 한국현대사 3` | `matched` |
| `역사와사상 한국현대사 4` | `conflict` |
| `문화와예술 한국현대사 3` | `conflict` |

`normalizeQuote`는 공백만 제거하고 쉼표는 남깁니다. 이후 표 검사기는 영역명 바로 다음에 과목명이 붙어 있어야 표 인용으로 인식합니다. 따라서 실제 셀 관계가 맞아도 쉼표가 있으면 표 검사에서 빠지고, 연속 텍스트 검사에서도 탈락합니다.

실패 인용 중 **16개는 기존 표 색인의 같은 행·병합셀 관계를 그대로 유지하면서 셀 사이 쉼표만 구분자로 처리하면 매칭되는 것**을 확인했습니다. 숫자나 문장부호를 일괄 삭제해서 얻은 결과가 아닙니다. 원본 응답을 바꾸거나 공식 점수를 갱신하지 않은 진단입니다.

관련 코드: [표 매칭](../../src/adapters/table-citations.ts), [인용 검사와 출력 지침](../../src/adapters/source-citations.ts).

### 2. 표 색인 범위가 좁고 지침도 충분히 일관되지 않음

이번 색인은 53쪽 균형교양 표 하나만 다룹니다. 고전독서의 영역별 권수 표(16쪽), 학과별 필수 과목표(49·60쪽), 동일과목 표(30쪽)는 표 관계를 자동 검사할 수 없습니다.

예를 들어 16쪽의 영역별 권수를 제목과 값으로 이어 쓰면 실제 표의 정보와 맞더라도 추출본의 연속 문자열이 아니어서 실패할 수 있습니다. 53쪽에서도 영역-제외계열만 묶거나 표 머리글·설명을 함께 넣는 표현은 현재의 영역-과목-학점 매칭 형식 밖입니다.

실행 요청에는 “53쪽 밖의 표는 셀 문구를 각각 인용”하라고 썼지만, 어댑터의 공통 지침은 색인 존재 여부만 보고 표 셀을 연결해도 된다고 안내합니다. 실제 지원하는 페이지·표·표현을 한 곳에서 명확히 알려야 합니다. 지원하지 않는 표는 관계 미검증으로 구분해야 하며, 같은 페이지에 단어가 있다는 이유로 통과시키면 안 됩니다.

### 3. 따옴표 차이를 근거 오류와 같은 실패로 표시함

편람의 곡선 따옴표 `‘문화와예술’`를 모델이 `'문화와예술'` 또는 `"문화와예술"`로 쓰면 현재 비교는 불일치로 처리합니다. 이처럼 따옴표 모양이나 유무만 다른 인용이 15개였습니다.

엄격한 직접 인용 규칙에서는 형식 위반일 수 있지만, 정책 내용이 틀렸다는 결론과는 다릅니다. 안전한 인용부호 정규화와 오류 분류가 필요합니다. 소수점·부호·범위 구분자까지 지우는 방식은 사용하지 않아야 합니다.

## 실제로 잘못된 인용도 있음

- `CS-2026-2-014 / C`: 30쪽에서 `세계사:인간과문명 → 세계사`를 **대체과목**으로 인용하고 본문에서도 동일과목이 아니라고 답했습니다. 실제 PDF에서는 **동일과목** 병합셀 안의 2023년 항목입니다. 이것은 표 관계를 잘못 읽은 오류입니다.
- `CS-2026-2-018 / B`: 원문의 `2012학년도`를 `2012학번도`로 바꿔 썼습니다. `CS-2026-2-010 / C`의 `자율선택 → 자유선택` 등도 직접 인용 오류입니다.
- `CS-2026-2-006 / A`: 두 인용에 `pdf_page=48;]`처럼 세미콜론을 하나 더 넣었습니다. 이 때문에 형식뿐 아니라 판본·페이지 등 여러 실패 플래그가 함께 생겼습니다. 각각 별개의 판본 오류가 난 것으로 세면 안 됩니다.
- `CS-2026-2-016 / A`: 4쪽의 두 항목을 인용했지만 그 PDF 페이지를 읽은 기록은 없습니다. 편람 텍스트에 근거가 있는지와 별개로, 이번에 요구한 원본 페이지 확인 절차는 빠졌습니다. 이 2개는 위 분류와 중복됩니다.

반대로 `CS-2026-2-011 / A`는 인용 검사를 통과했어도 정답 필드가 불일치했습니다. 인용문의 존재 확인과 해당 학생·질문에 규정을 적용한 판단은 따로 검토해야 합니다.

## C의 Skill 참조 누락

| 필수 파일 | 전체 읽기가 확인된 답변 |
| --- | ---: |
| Skill wrapper | 20/20 |
| query Skill 본문 | 20/20 |
| CLAUDE.md | 19/20 |
| PROJECT.md | 11/20 |

9개 답변에서 `PROJECT.md`가 빠졌고, 그중 `CS-2026-2-013 / C`는 `CLAUDE.md`도 빠졌습니다. 누락 파일을 읽으려다 실패하거나 일부만 읽은 경우가 아니라, 해당 파일을 대상으로 한 Read 요청 자체가 없었습니다. 20건의 실행 기록은 모두 완전하고 프로세스 시간 초과도 없었습니다.

따라서 “Skill 본문이 전혀 전달되지 않았다”는 상황은 아닙니다. 본문은 읽었지만 공통 규칙까지 따라 읽는 절차가 9건에서 끊겼습니다.

현재 연결 방식은 네이티브 Skill 실행을 끄고 파일을 문서로 읽게 합니다. `CLAUDE.md`의 `@docs/agent-harness/PROJECT.md` 참조를 실행기가 미리 펼쳐 전달하는 구현도 없습니다. 모델에 필수 파일 전체 읽기를 요청하지만, 누락 검사는 답변이 완성된 뒤에 수행합니다. 누락을 발견해 같은 실행 안에서 읽고 보완하게 하는 단계는 없습니다.

또한 기본 프롬프트의 “관련 있는 Skill을 골라 읽기”와 추가 지침의 “모든 Skill 파일을 읽기”가 함께 있습니다. 지시를 일관되게 정리할 필요가 있습니다. 이것이 각 요청에서 누락을 유발한 정확한 내부 이유인지는 저장된 기록만으로 확정할 수 없습니다.

`CS-2026-2-003 / C`는 인용 검사를 통과했지만 `PROJECT.md` 누락 때문에 정상 응답으로 채택되지 않았습니다. C의 인용 통과가 2건인데 채택은 1건인 이유입니다.

## 다음 수정 순서

1. 실제 실패 인용을 회귀 사례로 고정하고, 셀 경계의 구분자·인용부호 처리부터 보완합니다. 잘못된 학점·영역·지정 유형은 계속 거부해야 합니다.
2. 원문 인용 형식 오류, 지원하지 않는 표, 실제 내용 충돌, 원문 페이지 미확인을 나눠 보고합니다. 인용 지원 범위도 지침과 검사기가 같은 정의를 사용하도록 맞춥니다.
3. C가 “Skill 내용을 제공받은 상태의 답변 품질”을 비교하는 조건이라면 필수 문서 4개를 실행기가 먼저 읽어 입력에 포함하는 방식을 검토합니다. 이때 현재의 Read 호출 기반 지표와는 구분해 자료 전달 기록을 남겨야 합니다. 에이전트의 자율 탐색을 평가하려면 참조 읽기 성공률을 별도 지표로 유지합니다.
4. 저장된 60개 답변으로 검사기를 다시 확인한 뒤, 실제 모델 호출이 필요한 부분만 재평가합니다.
