# 쉼표·인용부호 보완 후 저장 답변 재검사

2026-11-15, [앞선 분석](remaining-111-offline-audit.md)에서 확인한 표 구분자·인용부호 문제를 고친 뒤 같은 답변 60개를 재검사했습니다. 모델 호출은 0회이며 원래 질문·답변·읽기 기록·점수는 덮어쓰지 않았습니다.

| 조건 | 이전 인용 검사 | 새 인용 검사 |
| --- | ---: | ---: |
| A | 2/20 | 6/20 |
| B | 2/20 | 4/20 |
| C | 2/20 | 5/20 |

개별 인용은 176개 중 69개 통과에서 99개 통과로 바뀌었습니다. 답변 내용의 개선이 아니라 같은 답변에 대한 검사기 판정 변경입니다. 정답 필드와 본문의 정확성, C의 필수 파일 읽기 성공, 사람 검토 통과와 구분합니다.

## 달라진 판정

- 같은 표 색인의 행·병합셀 관계를 유지한 쉼표 구분 인용 16개가 통과했습니다.
- 인용부호 모양·유무 차이 15개는 원문 문구와 대응됨을 확인했습니다. 이 중 1개는 인용한 PDF 페이지를 읽지 않았으므로 최종 인용 검사는 여전히 실패합니다. 따라서 통과 인용은 31개가 아닌 30개 늘었습니다.
- 기존에 통과한 인용과 답변은 계속 통과했습니다.

## 계속 잡는 오류

- 단어 변경 10개, 잘못된 표 관계 1개, 인용 메타데이터 형식 오류 2개는 모두 거부했습니다.
- 원본 PDF 페이지 읽기 기록이 없는 인용 2개도 계속 거부했습니다. 위 오류 수와 중복될 수 있습니다.
- 회귀 테스트에서 학점·영역·제외계열을 바꾼 표, 일부만 가져온 제외계열, 셀 안의 쉼표 삭제, 소수점·음수·범위 변경, 추가 설명을 붙인 인용을 거부했습니다.
- 지원하지 않는 표나 표 머리글·설명을 섞은 인용을 일괄 통과시키지 않았습니다. 남은 실패는 별도 검사 범위 확장과 원문 대조가 필요합니다.

## 검증 기록

재검사는 `source-recheck`를 사용했습니다. 60개 요청·답변·읽기 기록·원문 해시를 검증한 뒤 별도 파일에 결과를 저장했고, 과거 답변 해시가 그대로인지 다시 확인했습니다. [항목별 변경과 남은 실패](citation-format-recheck.observations.json)에 `checker_version: citation-format-3`, 이전/이후 상태, 변경된 인용 번호와 원본 입력 해시를 기록했습니다.

C의 문서 전달 방식 개선은 다음 PR의 별도 실행 조건입니다. 이 재검사로 과거 C의 참조 누락이 해결된 것으로 처리하지 않았습니다.
