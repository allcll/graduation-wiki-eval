## 절차

1. 질문의 적용 판본, 입학년도, 전공 유형과 판정 범위를 먼저 확인한다. 필요한 조건이 없으면 확인 가능한 부분과 추가 질문을 구분한다.
2. `INDEX.md`와 해당 `cohort/<학번>/<카테고리>.md`를 탐색 지도로 사용하고, **질문에서 지정한 판본의 제공된 원문**에서 적용 대상·규정·표·각주를 직접 대조한다. WIKI에 설명이 있어도 원문 확인을 생략하지 않는다. WIKI 인용 판본이 질문과 다르면 그 차이를 명시한다. 지정 판본이 제공되지 않았거나 근거 충돌이 해소되지 않으면 확인을 요청한다.
3. 해당 학생에게 적용되는 제외·대체·중복·재수강 규칙을 확인한다. 이수 과목을 제외하거나 다른 분류로 옮기는 경우에는 그 처리를 허용하는 원문 근거가 필요하다.
4. 계산을 다음 세 항목으로 분리한다.
   - **영역·종류의 수:** 규정에서 요구하는 서로 다른 분류의 개수를 센다.
   - **이수 학점 합계:** 적용 대상에 포함되는 서로 다른 이수 과목의 취득 학점을 합산한다. 같은 분류에 속한다는 이유만으로 과목의 학점을 제외하지 않는다. 실제 학점이 없으면 임의의 과목별 취득값을 만들지 않는다.
   - **필요 기준과 상한:** 충족에 필요한 최소 학점을 이수 합계의 상한으로 사용하지 않는다. 상한·중복 제한이 명시된 경우에만 해당 조건과 근거에 따라 적용한다. 적용 여부를 판단할 근거가 부족하면 그 불확실성을 남긴다.
5. 질문에서 요청한 각 출력값을 위 계산과 연결하고, 계산 과정과 최종 값이 모순되지 않는지 확인한다. 전체 졸업 가능 여부, 현재 시스템의 오류 원인, 수정 완료 여부 등 확인하지 않은 범위까지 결론을 넓히지 않는다.
6. 실제 확인한 원문의 판본·페이지·표 또는 항목을 답변에 인용한다. 다른 판본의 WIKI 인용을 지정 판본의 확인으로 대신하지 않는다. 표 배치가 모호하면 허용된 PDF 읽기 도구로 해당 페이지를 확인한다. 제공되지 않은 도구를 실행했다고 보고하지 않으며, 남은 불확실성은 추가 확인 사항으로 안내한다.
