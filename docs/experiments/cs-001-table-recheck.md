# 저장된 C 답변의 표 인용 다시 검사하기

2026-11-15, 검사 기준을 보완하고 **기존 C 답변을 그대로 재검사해 인용 6개 모두 통과**했습니다. 추가 모델 호출은 없었습니다. 처음의 2개 통과·4개 실패 기록과 실행 오류 보고서는 보존했습니다.

## 수정한 기준

최초 검사는 PDF의 평문 추출본에서 인용 문구가 연속해서 나타나는지만 확인했습니다. 표의 여러 셀을 연결한 인용을 확인하지 못했고, 실제 존재하는 `학점 합계 6`도 최소 8자 조건에 걸렸습니다.

이번에는 두 가지를 바꿨습니다.

1. **최소 8자 제한 제거.** 비어 있지 않은 실제 문구라면 짧아도 대조합니다. 출력 크기를 제한하는 최대 600자 조건은 유지했습니다.
2. **표 셀 관계 검사.** PDF 53쪽의 균형교양 표 전체에서 추출한 셀 좌표·행·열·병합 범위를 사용합니다. 과목과 학점은 같은 행이어야 하고, 영역과 제외 계열은 인용한 모든 행을 포함해야 합니다.

셀의 단어가 같은 페이지에 있다는 것만으로 통과하지 않습니다. 다른 영역의 과목, 같은 영역 내 다른 행의 학점, 다른 영역의 제외 계열을 섞으면 실패합니다. 표 관계가 충돌하면 평문 문자열이 우연히 일치해도 통과시키지 않습니다.

검사 함수에 특정 과목명이나 이 사례의 정답을 하드코딩하지 않았습니다. [표 인덱스](../../datasets/graduation-2026-2/source-indexes/README.md)는 질문별 정답 대신 해당 표 전체의 셀 50개와 원문 PDF 해시를 담으며, 모델에 전달하지 않는 채점 자료입니다. AI가 추출하고 PDF 이미지와 대조했으며 사람 검토는 대기 중입니다.

## 재검사 방법

```sh
node dist/cli.js source-recheck \
  --job artifacts/cs-001-source-check-2026-11-15/jobs/C-0001-001 \
  --source-contract context/sources/original/source-contract.json \
  --table-index datasets/graduation-2026-2/source-indexes/handbook-2026-2-p53.tables.json \
  --out artifacts/new-source-recheck/recheck.json
```

요청·답변·도구 기록·원문의 해시를 먼저 대조합니다. 답변을 고쳤거나 다른 요청의 도구 기록을 붙이면 검사 전에 중단합니다. 출력은 새 파일에만 저장하며, 구독 로그인이나 API 키가 필요하지 않습니다.

이번 로컬 결과는 `artifacts/cs-001-source-recheck-v2-2026-11-15/recheck-verified.json`입니다. [공개 관찰 기록](cs-001-table-recheck.observations.json)에는 같은 응답이라는 해시, 재검사 결과, 검사 코드와 인덱스 해시를 남겼습니다. 이전 [실패 관찰 기록](cs-001-source-verification.observations.json)은 수정하지 않았습니다.
