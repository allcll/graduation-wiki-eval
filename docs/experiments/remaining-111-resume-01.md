## 유지한 조건

원래 333개 작업의 계획 파일과 요청·자료를 새 폴더에 복사했습니다. 전체 계획의 해시는 `sha256:edd41b6dd7369fd5bcf134f158fcd192eb04883b43e7f1938a6bc3d1408103bb`로 동일합니다. 새 작업 폴더에는 `request.json`과 `context/`만 있고 이전 답변·검토 내용은 없습니다.

모델, 프롬프트, 질문·입력, 2026-2 편람, WIKI 69개 파일, Skill 4개 파일, 턴·시간 제한, 모델 연결 코드와 인용 검사기는 바꾸지 않았습니다. Claude Code 2.1.325와 Node.js 24.4.0도 같습니다. 실행기만 선택한 작업을 호출할 수 있도록 보완했습니다.
