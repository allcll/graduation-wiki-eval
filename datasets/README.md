# 평가 데이터셋

WIKI와 Skill의 답변 품질을 같은 질문과 기준으로 비교하기 위한 데이터입니다. 실행 코드와 함께 버전 관리해 팀원이 별도 비공개 레포에 접근하지 않아도 질문·정답·채점 기준을 확인할 수 있습니다.

| 데이터셋 | 문항 | 용도 |
| --- | --- | --- |
| [2026-2 졸업요건 v1](graduation-2026-2/v1/README.md) | 112 | 편람 기반 QA 개발·회귀 평가 |

`src/`는 실행·채점 도구, `datasets/`는 질문·정답·검토 기록, WIKI는 평가 대상 지식입니다. 레포는 함께 사용하되 모델 입력은 분리합니다. `datasets/`와 검토 화면을 모델의 컨텍스트에 넣지 않습니다.
